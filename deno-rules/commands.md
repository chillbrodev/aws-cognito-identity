# Common Deno Commands

```bash
# Run a script
deno run --allow-net script.ts

# Run with watch mode
deno run --watch --allow-net script.ts

# Install dependencies (cache them)
deno install

# Format code
deno fmt

# Lint code
deno lint

# Type check
deno check

# Run tests
deno test

# Run tests with coverage
deno test --coverage

# Run tests in watch mode
deno test --watch

# Run specific test file
deno test path/to/test.ts
```
