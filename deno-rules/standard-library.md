# Deno Standard Library

Deno provides a standard library (`@std/*`) with common utilities:

- `@std/expect`: Testing assertions
- `@std/testing/bdd`: BDD-style test framework
- `@std/testing/mock`: Stubbing and spying utilities
- `@std/fmt/colors`: Terminal colors
- `@std/dotenv`: Environment variable loading
- `@std/path`: Path manipulation
- `@std/datetime`: Date/time utilities
- `@std/crypto`: Cryptographic functions
- `@std/log`: Logging utilities
- `@std/assert`: Assertion utilities
